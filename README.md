# Lab 4b – Client-Side Scripting (JSON and jQuery)

BIC21203 Web Development, UTHM

## Files

- `books.json` – Q1: JSON dataset (top-level `books` array, 2 books)
- `books.html` – Q2: loads `books.json` with `fetch()` and displays results on the page
- `jquery-dom.html` – Q3: jQuery 4.0.0 (full build) equivalents of three native DOM operations

## Setup

1. Clone the repo: `git clone <your-repo-url>`
2. Open the folder in VS Code and install the **Live Server** extension.
3. Right-click `books.html` > **Open with Live Server** (do not open via `file://`, `fetch()` will fail).
4. `jquery-dom.html` can be opened the same way
   Alternative server: `python -m http.server 8000`, then visit http://localhost:8000/books.html
